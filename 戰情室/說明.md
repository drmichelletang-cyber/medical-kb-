# 叮噹戰情室 — 說明

一人公司的全員戰情儀錶板。**真相來源 = 這個資料夾裡的 `.md` 檔**，與醫學知識庫同一套哲學：改 `.md`，重生 HTML，永遠不要手改 HTML。

## 這版是什麼（L0：靜態快照）
資料放 `.md` → 跑產生器 → 重生 `戰情室.html`。「即時」＝最近一次重生的快照。最簡單、零維護壓力。
日後若要升級成「agent 自己回報、頁面自動刷新」（L1/L2），頁面結構不用重做，只要換資料來源。

## 重生 HTML
```bash
python3 戰情室/_tools/產生戰情室.py
```

## 資料夾
- `員工/` 每位員工／agent 一檔（`type: employee`）
- `專案/` 每個專案一檔（`type: project`），含負責人、進度、狀態、截止日
- `KPI/` 每個 KPI 一檔（`type: kpi`），年度／本月
- `會議/` 每場會議一檔（`type: meeting`），議程／決議／待辦寫在內文
- `_範本/` 新增時照這裡的格式
- `_tools/` 產生器

## Frontmatter 欄位（扁平、與知識庫同一套解析）
- **員工** `emp_id`（代號，給專案/會議參照）`avatar` `role` `kind`(agent/human) `state`(working/meeting/review/blocked/idle/offline) `doing`(最後在做什麼) `order`
- **專案** `proj_id` `owner`(emp_id) `collaborators` `status` `progress`(0–100) `priority` `start` `due` `kpi`
- **KPI** `kpi_id` `scope`(annual/monthly) `period` `current` `target` `unit` `owner`
- **會議** `meet_id` `date` `attendees`(emp_id 陣列) `projects` `tag` `recording`(Zoom 連結)

## 新增一筆怎麼做
1. 複製 `_範本/` 對應範本到對應資料夾，改檔名。
2. 填 frontmatter，內文照標題寫。
3. 跑產生器重生 HTML。

## 維護節奏（建議）
- 員工名單：幾乎不動。
- KPI：月初設、月底看。
- 專案進度：每週花幾分鐘更新 `progress` 與 `status`。
- 會議：開完會把重點存成一檔（之後可接 Zoom 自動抓）。
- **關鍵不在程式，在每週是否持續餵入真實狀況。**

## 員工 `state` 對照
working 工作中 ｜ meeting 開會中 ｜ review 待審 ｜ blocked 卡住 ｜ idle 待命 ｜ offline 離線
